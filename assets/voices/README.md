# 連鎖ボイス

ゲーム専用のオリジナルの台詞を Windows System.Speech で合成した PCM WAV。
現行版 `cute-v2/`: プレイヤーは Microsoft Sayaka、CPUは Microsoft Ayumi。既存作品の声の模倣・切り抜きではありません。
プレイヤーは基準ピッチを18〜22%上げ、語尾をさらに8%上げる明るい調整。CPUは10〜14%、語尾は4%と控えめにして声の違いを残しています。SSMLで話速と語尾を別々に指定し、音声全体の単純な早回しはしていません。合成エンジンによって指定の反映度は異なります。
旧版は直下に保持。再生成は現行版のみ更新します。
再生成: Windows PowerShell / PowerShell の `tools/build_chain_voices.ps1`（該当音声がインストールされている環境）。

| 連鎖 | プレイヤー | CPU |
|---|---|---|
| 1 | いくよ！ | いくわよ！ |
| 2 | つながった！ | 見えたわ！ |
| 3 | いい感じ！ | 余裕よ！ |
| 4 | まだまだ！ | 負けないわ！ |
| 5 | 絶好調！ | 私の番よ！ |
| 6 | 止まらない！ | 止められない！ |
| 7以上 | フィーバー！ | フィーバーよ！ |

ブラウザの初回クリック・タップで音声を準備。7以上は同じファイルを使います。
「効果音 OFF」、一時停止、画面離脱、非表示で停止。高速連鎖では前の声を止め、最新の声を優先します。
読み込み失敗・音声再生が許可されていない場合もゲーム操作を妨げません。
