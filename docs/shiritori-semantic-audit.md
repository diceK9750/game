# 絵しりとり：絵と読み方の意味監査

確認日: 2026-11-01<br>
対象: NUMBER RUSH ローカル作業版、絵しりとり全81札<br>
対象データ: `shiritori.py` のカタログ（監査開始時759読み、修正後731読み）、各札に実際に使われる絵文字、`assets/shiritori/` の専用SVG、盤面・図鑑・履歴の表示分岐。

## 判断方法と範囲

札のID・代表読みだけで画像の種類を決めず、表示される絵と各読みを照合した。絵に描かれた本体、視認できる部位、正当な上位分類や広く使われる英語名は区別して確認した。明らかに別の物・別の状態を示すものと、絵だけでは種・産地・時刻を判別できないものを分けた。

表示は `shiritori-ui.js` が盤面と履歴、`shiritori-dictionary.js` が図鑑に渡し、`shiritori-ui.css` が専用SVGを指定する。専用画像のない札は端末の絵文字フォントに依存する。監査対象は次の81 IDであり、特定端末のすべての絵文字デザインを実機検証したという意味ではない。

- `apple, gorilla, trumpet, panda, daruma, camel, radish, dog, teddy, orange, turtle, glasses, cat, tree, moon, fox, mouse, ear, bee, butterfly, rabbit, guitar, octopus, bird, squirrel, melon, umbrella`
- `fish, eggplant, bell, trousers, ship, mushroom, ice, car, mountain, peach, bread, lion, top, pillow, otter, koala, ramune, tie, chair, zucchini, chicken, backpack, scarf, radio, riceball, dragon`
- `cow, salt, plate, lavender, diamond, beans, medaka, sand, pot, bagel, loupe, paint, knife, tomato, parsley, sewing_needle, snow_crab, blocks, golf, gift, lipstick, gloves, snowman, grapes, curry, pudding, thread, candle`

## 明白な不一致：28読み

次は画像と異なる物、状態または模様を指す読みであり、プレイ・図鑑の有効な候補から外した。積み木とパセリには後述の専用SVGを用いる。

| 札と表示画像 | 対象となる読み | 判断理由 |
|---|---|---|
| りんご 🍎 | すりおろしりんご | 画像は丸ごとの赤いりんごで、すりおろした状態ではない。 |
| ラムネ瓶SVG | シャンパン、シャンペン、スパークリングワイン、コルク、ワイン、ワインボトル | ビー玉入りのラムネ瓶を描いており、ワインやコルクは描かれていない。 |
| ズッキーニSVG | きゅうり、キューカンバー、ピクルス、つけもの | 花付きの生ズッキーニであり、別の野菜や加工済みの漬物ではない。農水省もキュウリに似た形のカボチャの仲間と説明している。 |
| コマSVG | うずまき、スパイラル、うず、らせん、うずまきもよう、サイクロン、ハリケーン、たいふう、たつまき、トルネード | 円状に回転する玩具であり、らせん模様、渦、気象現象そのものは描かれていない。 |
| 積み木SVG | れんが、ブリック、レンガづみ、レンガブロック、かべ | 四角・三角・円筒の個別の玩具を描いており、レンガ造りの壁は描かれていない。 |
| パセリSVG | バジル、ミント | パセリとして描く場合、バジル・ミントは別の植物である。 |

「すりおろしりんご」は従来の別読み再合流にも使われていた。表示との一致を優先して候補から外したため、その特定の別読みからの再合流経路は利用できない。「しんしゅうりんご」の読みは残す。初期完走ルートは、実際の盤面と補充を使って再認証する。

## 新たな専用画像

従来の汎用絵文字では種や素材を特定しにくかった札について、次の6つのSVGを確認した。盤面・図鑑・履歴で同一の専用画像を参照する構成としている。

| ファイル | 描画内容と目的 |
|---|---|
| `assets/shiritori/medaka.svg` | 細身の魚。一般的な魚絵文字との種の不明瞭さを減らす。 |
| `assets/shiritori/snow_crab.svg` | 長い脚のカニ。一般的なカニ絵文字との差を明確にする。 |
| `assets/shiritori/blocks.svg` | 三角・四角・円筒の積み木。レンガ壁と区別する。 |
| `assets/shiritori/parsley.svg` | 縮れた葉の束。汎用の草絵文字よりパセリらしくする。 |
| `assets/shiritori/mushroom.svg` | 白い丸いマッシュルーム。赤い斑点の一般的なキノコ絵文字との差を明確にする。 |
| `assets/shiritori/paint.svg` | 開いたペンキ缶と絵の具パレット。塗料と画材の両方を示す。 |

従来の🎨だけでは「ペンキ」の表示が不明瞭だったため、`paint.svg` ではペンキ缶をパレットとともに描いた。「ペンキ」は現行の固定画像で対応する読みとして残す。

キノコのイラストはゲーム表現であり、色や見た目だけで実物の食用・毒性を判断するための図鑑ではない。実際のキノコの安全性は専門家による確認が必要。

## 画像からは断定しない読み

画像が抽象的、または背景情報が不足するだけで、必ず不一致とはいえない例は別扱いとする。

- **しんしゅうりんご**: 赤いリンゴの産地は絵から特定できないが、信州産の可能性を否定できない。
- **ウミガメ／りくがめ**: 🐢は一般的な亀の絵で、描画は端末ごとに異なる。Unicodeの関連語には `tortoise` もある。
- **ゆうづき／よぞら**: 🌙は三日月を示すが、夕方か夜か、空全体が描かれているかは画像だけでは確定しない。
- **きせん／クルーズシップ**: 🚢は船または客船を表すが、動力や運航形態は絵から特定できない。
- **ひがさ／ランドセル**: 傘の用途、鞄の細かな形状は、文脈や端末別の絵柄によって判断が分かれる。
- **🪻のヒヤシンス／ラベンダー／ルピナス**: Unicodeの短名はhyacinthだが、関連キーワードにlavenderとlupineも含む。
- **🦦のラッコ／カワウソ**: Unicodeへの提案ではsea otterとriver otterの両方を関連語に挙げている。
- **🍞のトースト**: Unicodeの `bread` の関連語に `toast` と `loaf` が含まれる。絵文字の描画差だけで一律に否定しない。

これらは画像が必ずその属性を示しているという意味ではない。後日、札ごとの表現方針を厳密化する際には、絵の変更、表示名、既存記録への影響を併せて検討する。

## 既存記録と検証の扱い

図鑑の保存キーは「札ID＋読み」であり、現行カタログから外れた旧キーも `retained` で保持する。意味の異なる旧読みを、無関係な新しい読みの発見として自動加算しない。たとえば「ワイン」を「ラムネ」の発見に置き換えることは、発見していない読みを発見済みにするため行わない。無効化された旧読みは現行図鑑の総数・発見数に含まれないが、旧キーは保持する。

先の助詞を含む旧読み73件については、意味が合う72件を同じ札の有効な読みへ引き継ぐ。今回、旧「ヒヤシンスのはな」の引き継ぎ先を「ヒヤシンス」、旧「えのぐのパレット」を「パレット」、旧「フォークとナイフ」を旧語に含まれる「フォーク」に修正した。フォークとナイフの発見を、別の物である「おさら」の発見として加算しない。積み木画像と意味が異なる旧「レンガのかべ」は引き継ぎ先なしとし、発見を新たに加算せず元キーを保持する。

旧読みの退役や画像変更後は、旧保存データを使った再読込、候補一覧と自動回答、盤面・図鑑・履歴の表示、12／24／36／48枚の初期完走、山札補充とフォールバックを確認する。継続枚数や新札出現頻度は同一条件で実測し、未検証の改善を断定しない。iPhone・Android等の実機確認と、コミット・公開の有無は各作業の実施結果に従う。
