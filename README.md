# NUMBER RUSH

Pythonと[Pyxel](https://github.com/kitao/pyxel)で作った、反射神経を測る数字タップゲームです。
5行×8列の40マスにランダム配置された数字を探す、横長画面向けのゲームです。

- **数字の範囲** — `1～10`、`1～20`、`1～30`、`1～40`から選べます。
- **ORDER MODE** — 選んだ範囲の数字を1から順番に探します。
- **RANDOM MODE** — 選んだ範囲のお題を重複なしでシャッフルし、表示された順番に探します。

どの範囲でも盤面は5行×8列のままです。例えば`1～10`では、40マスの中に1～10をランダム配置し、残り30マスは押せないロックパネルになります。

## ブラウザで遊ぶ

公開ページ: https://dicek9750.github.io/game/

1. `1-10`、`1-20`、`1-30`、`1-40`から数字の範囲を選びます。
2. `START ORDER` または `START RANDOM` を選びます。
3. `3・2・1` のカウントダウン後、数字の表示とタイム計測が同時に始まります。
4. 画面下中央の `FIND THE` に表示された数字を盤面から探します。
5. 正しい数字を押すとパネルが `OK` と模様でロックされ、次のお題が表示されます。
6. 選んだ範囲の数字をすべて見つけると、タイム・スコア・ミス数・最大連続正解数が表示されます。
7. `PLAY AGAIN` で同じ範囲・ルールを再プレイ、`MODE SELECT` で選択画面へ戻れます。

間違ったマスを押すと、そのマスが赤くなり、`MISS!` と表示されます。ゲームは止まらず、連続正解数だけが0に戻ります。PCではマウス、スマートフォンでは横持ちのタッチ操作を前提としています。

## 遊びやすさとスコア

- `RETRY` — 確認後、同じ範囲・ルールを新しい配置でやり直します。
- `TITLE` — 確認後、範囲・ルール選択へ戻ります。
- `BGM ON/OFF` — オリジナルのチップチューンBGMを切り替えます。
- `SFX ON/OFF` — 正解・ミス・クリアなどの効果音を切り替えます。
- 確認画面では盤面を隠し、タイマーも一時停止します。
- 盤面を囲む40個のセグメントと左の縦ゲージで進行が分かります。
- 青緑のカワウソ探検家と橙色のキツネライバルが、正解・ミス・チェックポイントに反応します。
- 選んだ範囲の25%・50%・75%付近でチェックポイント表示が出ます。50%・75%ではBGMの演奏が一段ずつ厚くなります。
- 正解1個につき100点に加え、連続正解数×10点（最大200点）のボーナスが入ります。ミスによる減点はありません。
- 4つの範囲×2つのルールの8通りごとに、ページを開いている間の最速タイムを記録します。

選択画面のキーボード操作は、`1`～`4`で範囲選択、`O`でORDER開始、`R`でRANDOM開始です。ゲーム中は`R`でリトライ、`T`でタイトル、`B`でBGM切替、`S`で効果音切替、確認画面では`Y` / `N`が使えます。

> 初回表示ではPyxelのWebランタイムを読み込むため、ゲーム開始まで少し時間がかかる場合があります。

## ローカルで起動する

### ブラウザ版（Pythonのインストール不要）

HTMLからPythonファイルを読み込むため、`index.html` を直接ダブルクリックするのではなく、ローカルWebサーバーを使います。

Python 3がインストール済みの場合、リポジトリのフォルダーで次を実行します。

```powershell
python -m http.server 8000
```

その後、ブラウザで http://localhost:8000/ を開いてください。ゲーム本体はブラウザ内で実行されるため、ローカルへのPyxelインストールは不要です。

### デスクトップ版

Python 3.11以降をインストールし、次を実行します。

```powershell
python -m pip install -r requirements.txt
python game.py
```

## GitHub Pagesへの公開

`.github/workflows/pages.yml` が、`main` ブランチへのpush時に自動でGitHub Pagesへ公開します。
初回だけ、GitHubリポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選択してください。

## ファイル構成

- `game.py` — Pyxelで描画・入力・ゲーム進行を行うゲーム本体
- `game_logic.py` — 配置、正誤判定、一時停止を含むタイム計測を担う独立したロジック
- `index.html` — Pyxel Webを読み込み、PC・スマートフォン向けに表示するページ
- `requirements.txt` — デスクトップ実行用のPyxelバージョン
- `tests/test_game_logic.py` — ゲーム進行の自動テスト
- `.github/workflows/pages.yml` — GitHub Pagesの自動公開設定

## テスト

ゲームロジックのテストには外部ライブラリは不要です。

```powershell
python -m unittest discover -s tests -v
```

## 技術メモ

- ブラウザ版はPyxel 2.9.8のWebランタイムをCDNから読み込みます。
- BGMと効果音はPyxel内蔵の波形だけで作ったオリジナルです。外部の音声ファイルは使用していません。
- BGMは32音単位の32フレーズを全パート同じ長さに揃えた約76.8秒のループです。導入・応答・展開・クライマックスの4部で構成し、単純な短周期反復を避けています。
- 選んだ範囲の50%・75%到達時の演奏レベル変更は、曲中の現在位置を保ったまま次のフレーズ境界で反映されます。確認画面やBGM切替から戻った場合も、3パートを同じ位置から再開します。
- 2頭身キャラクターもPyxelの円・三角形・長方形だけで描画しており、外部画像は使用していません。
- タイムはフレーム数ではなく単調増加時計で計測するため、描画の遅れが結果に混ざりにくい構成です。
- ゲーム盤は横持ち用の640×360論理解像度で描画し、ブラウザ側で画面に合わせて表示します。
