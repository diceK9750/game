# NUMBER RUSH — Lantern League

Pythonと[Pyxel](https://github.com/kitao/pyxel)で動く、数字さがし対戦ゲームです。
PC・スマートフォンのブラウザで遊べます。5行×8列の盤面は固定で、1～10・20・30・40の数字範囲、順番・ランダムのお題を選べます。

ブラウザ版の文字・数字・ボタン・各画面をHTML/CSSで描画する構成へ更新。

最初の実行には通信が必要です。オフライン対応・App Store配信・全機種での動作保証は含みません。
比較対象のすべてのアプリを上回ることを保証するものではなく、操作性と安定性を重視した改修です。

## 遊び方

1. 起動後、ゲーム画面をクリック／タップします（初回は読み込みに少し時間がかかります）。
2. **CPUと対戦** か **ひとりで練習**を選びます。
3. `1-10 / 1-20 / 1-30 / 1-40` から数字範囲を選びます。少ない範囲でも40マスを使い、数字のないマスは無反応です。
4. 対戦の場合は 「ゆっくり / ふつう / てごわい」を選びます。
5. 「1から順番に開始」は順番、「ランダムで開始」は範囲内の数字を重複なくランダム順で出題します。
6. 3秒カウント後、中央の大きなお題と同じ数字をクリック／タップします。PCは矢印キーでカーソル移動、EnterまたはSpaceで決定もできます。

対戦は先に取った側が1点。全問終了時に60％以上（6・12・18・24点）を取れば勝利です。
獲得後は次のお題をすぐに表示し、待ち時間なしで入力できます。獲得結果とエフェクトは並行表示します。
CPUが取った直後も同様です。勝利ライン到達後も全問まで遊べます。

- 正解：リンが喜び、コウが悔しがります。青い獲得枠とチェック、`YOU +1`、回答秒数、連続正解数を表示します。
- ミス：リンが驚き、コウが喜びます。選んだマスで爆弾→爆発→煙の演出が出ますが、その数字は消えず、同じマスを選び直せます。
- CPU先取：ピンクの獲得枠と `CPU +1`、左右の反応を表示します。
- 探索カーソルは演出です。CPUの期限を変えたり、正解位置を特別に教えたりしません。
- CPUの探索時間は毎問抽選：EASY 4～6秒、NORMAL 2.4～4.2秒、HARD 1.3～2.6秒。
- ミスは1問に1回まで、CPUの残り時間を最大0.3秒短縮します。直後の猶予0.25秒を目安とし、既に迫った期限を延ばしません。同じフレームの入力はプレイヤー優先です。
- 速い正解の `LIGHTNING / QUICK / NICE` は評価表示で、対戦の追加得点ではありません。

練習ではCPUは数字を取りません。全問正解で時間・スコア・ミス・最大連続正解数を表示します。
正解は100点＋連続正解数×10点（ボーナス上限200点）。ミスで連続正解がリセットされますが、減点はありません。
練習の最速時間と対戦の最高得点は設定ごとに分けてブラウザ内に保存します。Python単体版と保存が利用できない場合は、起動中のみの記録です。

## 途中で休む・やり直す

- `RETRY`／R：確認後、同じ設定を新しい配置でやり直します。
- `TITLE`／T：確認後、モード選択へ戻ります。
- Esc：時計・CPUを止め、盤面を隠します。`RESUME`／Enterで2秒カウントして復帰します。停止画面からTITLEの確認もできます。
- 別のタブやアプリへ移ると、ブラウザの非表示イベントを受けて時計・CPU・音を停止します。対戦／練習に戻るときは明示的な復帰操作が必要です。
- `BGM ON/OFF`／B、`SFX ON/OFF`／S：音楽と効果音を別々に切り替えます。
- 選択画面の `HELP`／H：遊び方を表示。Enter・Esc・BACKで戻れます。
- 選択画面は数字キー1～4で範囲選択、Oで順番開始、Rでランダム開始。通常の確認はY／Nです。

キーボードはゲーム部分を一度クリックしてから使ってください。
Escはゲーム終了ではありません。デスクトップ版を終了するにはウィンドウの×を使います。
