# NUMBER RUSH — Lantern League

Pythonと[Pyxel](https://github.com/kitao/pyxel)で動く、絵しりとり・数字さがしゲームです。
スマートフォン横持ち → 縦持ち → PCの順に表示・操作を設計しています。
数字さがしは5行×8列固定で、1～10・20・30・40、順番・ランダムのお題を選べます。

## はじめにゲームを選ぶ

2026-09-08の総点検で、設定の即時保存と絵しりとり設定の復元、モード選択へ戻る際の確認、
完走時BGM、異常な保存データへの耐性、保存失敗の結果表示を改善しました。
点検範囲と確認の限界は [総点検記録](AUDIT-2026-09-08.md) を参照してください。

絵しりとりの先読みを改善しました。発見済みの完走ルートは、盤面・山札・使用済みの読み方が一致する場合に再利用します。
別の札を選んだり、つなぎ直した場合は現在の状態から再検討。再スタート時には以前の先読みを破棄します。
ヒントも先頭の正解札ではなく、完走優先・長く続く札を選びます。ヒントの回数は従来どおり3回で、探索中の時間は持ち時間から引きません。
「完走ルートを発見」はその後も適切な札を選んだ場合の可能性を示し、プレイヤーの完走を保証する表示ではありません。

共通操作は両ゲームで同じヘッダーを使用します。設定画面は「ゲーム選択／BGM／遊び方」、
プレイ中は「BGM／やり直す／一時停止」の順です（小さい縦画面では、やり直しは休憩メニュー内）。
絵しりとり側の下部にあったゲーム選択・休憩ボタンは重複表示しません。
モード選択は「CPUと対戦／ひとりで練習」、結果の操作は「もう一度遊ぶ／モード選択」に統一。
両ゲームの設定と休憩メニューから、効果音と演出を切り替えられます。
絵しりとりのヘッダーからのやり直しは、タイマーを停止して確認し、キャンセルで再開します。

両ゲームのトップ画面を、数字さがし基準の「キャラクター紹介＋設定カード」に統一しました。
絵しりとりにもリンとライバルのイラストを表示。ライバルの表示名は **LUNA（ルナ）** です。
トップ画面には物語設定ではなく遊び方を掲載し、枚数選択・一人用・辞書機能は維持しています。
内部の `koh` ID・画像ファイル名は互換性のため維持しています。以下の旧制作記録にあるコウは現在のルナです。

ライバルのコウは、悪堕ちしたレッサーパンダの女の子「闇の魔法少女」に変更しました。
闇の妖精にそそのかされて闇の力をまとった設定です。両ゲームのコウのそばに妖精を表示します。
背景付き画像を透過アトラスへ差し替え、森の背景がキャラクターの周囲に自然に見えるようにしました。
妖精は操作を遮らず浮遊し、端末の「視差効果を減らす」設定では静止します。
制作方法と最終プロンプトは [背景修正・闇の妖精](assets/characters/DARK-FAIRY-PROMPTS.md) に記録しています。
紫の長髪、黒と紫の衣装、闇の冠を持ち、通常・喜び・勝利・驚き・悔しさ・敗北の6表情を用意。
画像はimagegenスキルの組み込み生成で新規制作し、[生成プロンプト](assets/characters/KOH-DARK-PROMPT.md)を同梱しています。

両ゲームのCPU対戦では、紫色の外周枠とCPUラベルが隣接マスを1マスずつ移動し、回答する札で停止します。
横持ち・縦持ちの列数に合わせて経路を変更。演出はCPUの思考時間内に行い、回答後に待ち時間は追加しません。
探索途中は空欄・取得済みの位置を通る場合もありますが、それを回答として選ぶことはありません。
一人用・休憩中・結果画面では選択枠を出さず、数字さがしのプレイヤーのタップも妨げません。

起動後は「絵しりとり」「数字さがし」の2択だけを表示します。
ゲームを選んだ後、そのゲーム専用の設定画面に進みます。「ゲーム選択」で入口へ戻れます。

## 絵しりとり：一人用・CPU対戦

「絵しりとり」→「一人でじっくり／CPUと対戦」→「12／24／36枚」→スタート。
初回は一人用を選択済みにしています。設定はこのページを開いている間は保持します。
ブラウザ版専用の新モードで、Pythonが判定・時間・CPUを担当し、Pyxelが実行と音を担当します。
Python単体起動の従来画面には、このモードの入口はありません。

### 読み方ずかん：158種類のコンプリート

絵しりとりの設定画面・結果画面の「読み方ずかん」から開きます。
自分で正解した読み方をその場で登録します（ヒント利用も対象）。CPUの回答や結果一覧の閲覧だけでは登録しません。
同じ「くだもの」でも、りんごとみかんは別項目。全39絵・158項目の収集数と達成率、
絵ごとの完成マーク、未完成の絵だけの絞り込みを用意。未発見は「？？？」で伏せます。

「発見チャレンジ」は頭文字を見て最大6枚から絵を選ぶ、時間制限なしの収集練習です。
未発見の読みを出題し、正解を自動登録。通常しりとりでは使えない「ん」終わりも練習では登録でき、
全158項目が収集可能です。全項目が埋まると「ことばマスター」のコンプリート表示になります。
通常プレイのルールや数字さがしの記録には影響しません。

進捗は同じ端末・ブラウザ・サイトのlocalStorageへ保存します。ローカル版とGitHub Pages版では別保存です。
ブラウザのサイトデータ削除で失われ、プライベート閲覧や保存禁止設定では保持できない場合があります。
保存エラーは辞書に表示し、そのページ内では収集を継続できます。過去のプレイ分は遡って登録しません。

### プレイルール

- 39種類の絵札から総枚数12・24・36枚を選択。同時表示を最大24枚に増加。24枚表示は横持ち8列×3行、縦持ち4列×6行。12枚コースは横4列×3行／縦3列×4行です。
- 36枚コースは、使った位置に山札12枚から1枚ずつ補充。他の札は移動させず、補充はNEW表示で知らせます。演出中も札を選べます。
- 補充後の盤面に正解がなく山札にはある場合、補充した1枚だけを正解候補へ交換します。CPUにも同じルールを適用し、山札の中身は画面に公開しません。
- 絵を1回タップすると、必要な頭文字につながる未使用の読み方を自動確定。読み方を選ぶ画面はありません。「ん」終わりは自動で除外し、つながらない絵は消費しません。
- 全39種類に3〜5種類の読み方を登録。名称・別名・分類・絵に見える部位を含みます。同じ絵の中では頭文字がすべて異なるため、正解の読み方は一意です。例：ギターは「ぎたー／がっき／えれきぎたー／げんがっき」。自由入力辞書ではありません。
- 絵はパネルの短辺の約86%を基準に拡大し、取得済み・NEW表示は端に重ねて絵の場所を確保します。
- パネルは正方形を基本に、高さが足りない画面では横長に調整。縦長には引き伸ばしません。
- パネル間隔は縦横とも4px固定。余った高さは盤面の外側にまとめ、行間に大きな空白を作りません。
- ヒントの該当札は金色の太枠・光・「◆ ヒント」ラベルで強調。選択するまで表示し、演出中もタップできます。動きを減らす設定では静止表示します。
- 対戦：交互に回答。時間切れ・つなげる札がないと負け。持ち時間は一手30／20／12秒、誤答は−3秒。全難易度でルナは全札完走（パーフェクト）につながる手を優先し、見つからなければ探索で確認できた最長の続きを選びます。全札を使い切ると引き分けです。
- 先読みは使用済みの札・同じ読み方の再使用・「ん」終わり・山札の順序と補充救済を考慮します。各候補に公平に探索量を割り当て、最大4096状態を探索。上限に達した場合は最長・完走不可能の証明ではありません。プレイヤーの次の選択によってルートは変わるため、毎回選び直します。難易度による持ち時間は従来どおりです。
- 一人用：時間制限もCPUの割り込みもありません。詰まった場合は2回まで「つなぎ直す」で別の文字から再開でき、全札使用でクリア。つなぎ直しを使い切って詰まった場合は結果を表示します。
- 同じ札・同じことばは再使用不可。間違えても札は失わず選び直せます。
- ヒント3回、途中休憩、自動中断、やり直し、結果・ことば履歴を用意。一人用は休憩画面から任意に終了できます。
- 結果から別の読み方も復習できます。つなぎ直した地点は履歴に明示します。
- 独自ルール：小さいかなは大きく、長音は直前のかな（ぎたー→た）、濁点は区別。山札を含め、12枚では12手・24／36枚では14手の成立経路を含めますが、別の読み方で行き先が変わります。
- 絵は端末の標準絵文字と独自SVG。端末によって絵柄が異なります。キャラクターとBGMは既存のオリジナル素材を再利用し、原作の画像・音源は同梱していません。
- しりとりの勝敗・履歴は現在のプレイ内のみ。数字さがしの保存記録には加算しません。

新規ファイル：`shiritori.py`、`shiritori-ui.js`、`shiritori-ui.css`、`assets/shiritori/daruma.svg`、
`tests/test_shiritori.py`、`tests/test_shiritori_view.cjs`。

### v9.1追加：パーフェクト勝利のスペシャルボーナス

CPU DUELで、**全問を自分で獲得・CPUは0点・ミス0回**で最後まで勝利するとパーフェクトです。
すべての数字範囲・ORDER/RANDOM・難易度で適用します。通常勝利や練習クリアでは付与しません。

## 遊び方

1. 起動後、ゲーム画面をクリック／タップします（初回は読み込みに少し時間がかかります）。
2. **CPUと対戦** か **ひとりで練習**を選びます。
3. `1-10 / 1-20 / 1-30 / 1-40` から数字範囲を選びます。少ない範囲でも40マスを使い、数字のないマスは無反応です。
4. 対戦の場合は 「ゆっくり / ふつう / てごわい」を選びます。
5. 「1から順番に開始」は順番、「ランダムで開始」は範囲内の数字を重複なくランダム順で出題します。
6. 3秒カウント後、中央の大きなお題と同じ数字をクリック／タップします。PCは矢印キーでカーソル移動、EnterまたはSpaceで決定もできます。

対戦は先に取った側が1点。全問終了時に60％以上（6・12・18・24点）を取れば勝利です。
獲得後は次のお題をすぐに表示し、待ち時間なしで入力できます。獲得結果とエフェクトは並行表示します。
CPUが取った直後も同様です。勝利ライン到達後も全問まで遊べます。

- 正解：リンが喜び、コウが悔しがります。青い獲得枠とチェック、`YOU +1`、回答秒数、連続正解数を表示します。
- ミス：リンが驚き、コウが喜びます。選んだマスで爆弾→爆発→煙の演出が出ますが、その数字は消えず、同じマスを選び直せます。
- CPU先取：ピンクの獲得枠と `CPU +1`、左右の反応を表示します。
- 探索カーソルは演出です。CPUの期限を変えたり、正解位置を特別に教えたりしません。
- CPUの探索時間は毎問抽選：EASY 4～6秒、NORMAL 2.4～4.2秒、HARD 1.3～2.6秒。
- ミスは1問に1回まで、CPUの残り時間を最大0.3秒短縮します。直後の猶予0.25秒を目安とし、既に迫った期限を延ばしません。同じフレームの入力はプレイヤー優先です。
- 速い正解の `LIGHTNING / QUICK / NICE` は評価表示で、対戦の追加得点ではありません。

練習ではCPUは数字を取りません。全問正解で時間・スコア・ミス・最大連続正解数を表示します。
正解は100点＋連続正解数×10点（ボーナス上限200点）。ミスで連続正解がリセットされますが、減点はありません。
練習の最速時間と対戦の最高得点は設定ごとに分けてブラウザ内に保存します。Python単体版と保存が利用できない場合は、起動中のみの記録です。

## 途中で休む・やり直す

- `RETRY`／R：確認後、同じ設定を新しい配置でやり直します。
- `TITLE`／T：確認後、モード選択へ戻ります。
- Esc：時計・CPUを止め、盤面を隠します。`RESUME`／Enterで2秒カウントして復帰します。停止画面からTITLEの確認もできます。
- 別のタブやアプリへ移ると、ブラウザの非表示イベントを受けて時計・CPU・音を停止します。対戦／練習に戻るときは明示的な復帰操作が必要です。
- `BGM ON/OFF`／B、`SFX ON/OFF`／S：音楽と効果音を別々に切り替えます。
- 選択画面の `HELP`／H：遊び方を表示。Enter・Esc・BACKで戻れます。
- 選択画面は数字キー1～4で範囲選択、Oで順番開始、Rでランダム開始。通常の確認はY／Nです。

キーボードはゲーム部分を一度クリックしてから使ってください。
Escはゲーム終了ではありません。デスクトップ版を終了するにはウィンドウの×を使います。

```

python -m venv .venv

```
