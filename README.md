# NUMBER RUSH — Lantern League

Pythonと[Pyxel](https://github.com/kitao/pyxel)で動く、数字さがし対戦ゲームです。
PC・スマートフォンのブラウザで遊べます。5行×8列の盤面は固定で、1～10・20・30・40の数字範囲、順番・ランダムのお題を選べます。

## v9.0：キャラクター・音楽・舞台を全面改稿

夜の森の「ランタン大会」を舞台に、カワウソの **MILO（ミロ／プレイヤー）** とキツネの **RUBY（ルビー／CPU）** が対戦します。

- 2頭身キャラクターを描き直しました。青い探検ジャケットのミロ、額のゴーグルと紫のベストのルビー。大きな目、口、耳、尻尾、スカーフを別々に描き、呼吸・尻尾の揺れ・喜び・悔しさ・勝利のポーズを表現します。
- 暖かなランタン、木のステージ、クリーム色の数字カードと金色の枠で舞台を統一。自分の青、CPUのピンクの探索枠が区別できます。獲得済みカードは暗くして、残りの数字を探しやすくしました。
- 対戦・練習・選択・休憩・カウント・勝利・敗北の全7曲を新しく作曲。効果音も和音と音量を合わせて改稿しました。
- キャラクター・旋律・画像はすべてオリジナルです。既存作品の画像・音源や採譜データは含みません。
- 数字の大きさ、ボタン位置、iPhone向け表示、対戦ルール、ミスしたマスの再選択は維持しています。

## 遊び方

1. 起動後、ゲーム画面をクリック／タップします（初回は読み込みに少し時間がかかります）。
2. **CPU DUEL**（対戦）か **SOLO PRACTICE**（タイムアタック）を選びます。
3. `1-10 / 1-20 / 1-30 / 1-40` から数字範囲を選びます。少ない範囲でも40マスを使い、数字のないマスは無反応です。
4. 対戦の場合は `EASY / NORMAL / HARD` を選びます。
5. `START ORDER` は1から順番、`START RANDOM` は範囲内の数字を重複なくランダム順で出題します。
6. 3秒カウント後、中央の大きなお題と同じ数字をクリック／タップします。PCは矢印キーでカーソル移動、EnterまたはSpaceで決定もできます。

対戦は先に取った側が1点。全問終了時に60％以上（6・12・18・24点）を取れば勝利です。
正解後0.65秒は獲得結果を表示し、次の問題へ進みます。勝利ライン到達後も全問まで遊べます。

- 正解：ミロが喜び、ルビーが悔しがります。青い獲得枠とチェック、`YOU +1`、回答秒数、連続正解数を表示します。
- ミス：ミロが困り、ルビーが喜びます。選んだマスで爆弾→爆発→煙の演出が出ますが、その数字は消えず、同じマスを選び直せます。
- CPU先取：ピンクの獲得枠と `CPU +1`、左右の反応を表示します。
- 探索カーソルは演出です。CPUの期限を変えたり、正解位置を特別に教えたりしません。
- CPUの探索時間は毎問抽選：EASY 4～6秒、NORMAL 2.4～4.2秒、HARD 1.3～2.6秒。
- ミスはCPUの残り時間を最大0.3秒短縮します。直後の猶予0.25秒を目安とし、既に迫った期限を延ばしません。同じフレームの入力はプレイヤー優先です。
- 速い正解の `LIGHTNING / QUICK / NICE` は評価表示で、対戦の追加得点ではありません。

練習ではCPUは数字を取りません。全問正解で時間・スコア・ミス・最大連続正解数を表示します。
正解は100点＋連続正解数×10点（ボーナス上限200点）。ミスで連続正解がリセットされますが、減点はありません。
練習の最速時間と対戦の最高得点は設定ごとに分けて記録します。記録はページを開いている間だけ保存されます。

## 途中で休む・やり直す

- `RETRY`／R：確認後、同じ設定を新しい配置でやり直します。
- `TITLE`／T：確認後、モード選択へ戻ります。
- Esc：時計・CPUを止め、盤面を隠します。`RESUME`／Enterで2秒カウントして復帰します。停止画面からTITLEの確認もできます。
- 別のタブやアプリへ移ると、ブラウザの非表示イベントを受けて時計・CPU・音を停止します。対戦／練習に戻るときは明示的な復帰操作が必要です。
- `BGM ON/OFF`／B、`SFX ON/OFF`／S：音楽と効果音を別々に切り替えます。
- 選択画面の `HELP`／H：遊び方を表示。Enter・Esc・BACKで戻れます。
- 選択画面は数字キー1～4で範囲選択、Oで順番開始、Rでランダム開始。通常の確認はY／Nです。

キーボードはゲーム部分を一度クリックしてから使ってください。
Escはゲーム終了ではありません。デスクトップ版を終了するにはウィンドウの×を使います。

## PC・iPhoneの表示

ゲームは640×360の専用iframeで実行し、`viewport.js` が枠全体を拡大縮小します。
Safariの可視領域とセーフエリアに収め、Pyxel内部の最小倍率による切り取りを避けています。
画面回転やアドレスバーの伸縮ではゲームを再起動しません。縦向きでも収まりますが、数字・ボタンが大きくなる横向きをおすすめします。
今回この表示方式とボタン位置は変更していません。iPhone実機での最終確認は未実施です。

## ローカルで起動する

Python 3.11以降をインストールし、このフォルダーでターミナルを開きます。

### ブラウザ版

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

同じPCのブラウザで [ローカルゲーム](http://127.0.0.1:8000/) を開きます。
HTMLのダブルクリックではなく、このサーバーを使ってください。
ゲーム本体はブラウザ内で動くため、ブラウザ版にPyxelのローカルインストールは不要です。
初回のWebランタイム読み込みにはインターネット接続が必要です。終了はサーバーのターミナルでCtrl+Cです。

### デスクトップ版

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe game.py
```

### 画像・曲をゲームと同じエンジンで書き出す

```powershell
.\.venv\Scripts\python.exe tools/preview_assets.py
```

`build/preview/` にポーズ一覧、実際の画面PNG、全7曲のWAVを出力します。
対戦／練習のWAVは80.8秒で、76.8秒地点のループの継ぎ目も試聴できます。
`build/` と `.venv/` はGit対象外です。公開用ゲームにこれらのファイルは不要です。

## GitHub Pagesへの公開

[公開先](https://dicek9750.github.io/game/) は、ローカルだけの変更を反映しません。
`main` ブランチへのcommit・pushと、Pagesワークフローの成功が必要です。
初回はGitHubの **Settings → Pages → Build and deployment → Source → GitHub Actions** を選んでください。
今回、新しい `characters.py` も公開ファイルに含めるよう設定しました。commit・pushは自動では行っていません。

## 主なファイル

- `game.py` — 入力、画面、キャラクター反応、音楽の再生と切り替え
- `characters.py` — ミロとルビーの描画・全12ポーズ
- `music.py` — 全7曲の譜面、音色、強弱、曲構成
- `game_logic.py` — 数字配置、対戦、正誤判定、時計
- `index.html`、`player.html`、`viewport.js` — ブラウザ起動と可視領域へのフィット
- `requirements.txt` — デスクトップ用Pyxel 2.9.8
- `tools/preview_assets.py` — 本物のPyxelによる画像・音の書き出しとPCM検証
- `tests/` — ルール、画面、曲構造、キャラクター、表示サイズの回帰テスト
- `.github/workflows/pages.yml` — テストと静的サイトの公開
